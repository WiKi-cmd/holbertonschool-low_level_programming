## README
- 0-preprocessor contains a script that runs a C file through the preprocessor and save the result into another file called c, C file name saved in the variable $CFILE
- 1-compiler contains a script that compiles a C file but does not link, file name saved in the variable $CFILE
- 2-assembler contains a script that generates the assembly code of a C code and save it in an output file, file name saved in the variable $CFILE
- 3-name contains a script that compiles a C file and creates an executable named cisfun, file name saved in the variable $CFILE
- 4-puts.c contains a C program that prints exactly "Programming is like building a multilingual puzzle, followed by a new line, using puts
- 5-printf.c contains a C program that prints exactly with proper grammar, but the outcome is a piece of art,, followed by a new line, using printf
- 6-size.c contains a C program that prints the size of various types on the computer it is compiled and run on
