## README

- 0-reset_to_98.c contains a C function that takes a pointer to an int as parameter and updates the value it points to to 98
- 1-swap.c contains a C function that swaps the values of two integers
- 2-strlen.c contains a C function that returns the length of a string
- 3-puts.c contains a C function that prints a string, followed by a new line, to stdout
- 4-print_rev.c contains a C function that prints a string, in reverse, followed by a new line
- 5-rev_string.c contains a C function that reverses a string
- 6-puts2.c contains a C function that prints every other character of a string, starting with the first character, followed by a new line
- 7-puts_half.c contains a C function that prints half of a string, followed by a new line If the number of characters is odd, the function should print the last n characters of the string, where n = (length_of_the_string + 1) / 2
- 8-print_array.c contains a C function that prints n elements of an array of integers, followed by a new line
- 9-strcpy.c contains a C function that copies the string pointed to by src, including the terminating null byte (\0), to the buffer pointed to by dest, return value the pointer to dest
- 100-atoi.c contains a C function that convert a string to an integer

- 0-strcat.c contains a C function that appends a string to another
- 1-strncat.c contains a C function that appends n bytes of a string to another
- 2-strncpy.c contains a C function that copies a n bytes of a string into another
- 3-strcmp.c contains a C function that compares two strings (byte difference)
- 4-rev_array.c contains a C function that reverses the content of an array of integers
- 5-string_toupper.c contains a C function that changes all lowercase letters of a string to uppercase
- 6-cap_string.c contains a C function that capitalizes all words of a string (Separators of words: space, tabulation, new line, ,, ;, ., !, ?, ", (, ), {, and })
- 7-leet.c contains a C function that encodes a string into 1337

- 0-memset.c contains a C function that fills memory with a constant byte
- 1-memcpy.c contains a C function that copies n bytes from a memory area to another
- 2-strchr.c contains a C function that locates a character in a string
- 3-strspn.c contains a C function that gets the length of a prefix substring (Returns the number of bytes in the initial segment of which consist only of bytes from another segment)
- 4-strpbrk.c contains a C function that searches a string for any of a set of bytes
- 5-strstr.c contains a C function that locates a substring
- 7-print_chessboard.c a C function that prints the chessboard
- 8-print_diagsums.c contains a C function that prints the sum of the two diagonals of a square matrix of integers
