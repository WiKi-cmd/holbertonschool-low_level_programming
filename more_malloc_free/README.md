## README

- 0-malloc_checked.c contains a C function that allocates memory using malloc
- 1-string_nconcat.c contains a C function that concatenates n bytes of a string with another in a newly allocated space in memory
- 2-calloc.c contains a C function that allocates memory for an array, using malloc
- 3-array_range.c contains C function that creates an array of integers containing all values between min and max included
