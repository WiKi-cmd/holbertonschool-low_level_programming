## README

- all programs and functions here use a _putchar.c programm, no standard library
- prototypes of all the functions are in main.h
- 0-putchar.c contains a C program that prints _putchar, followed by a new line
- 1-alphabet.c contains a C function that prints the alphabet, in lowercase, followed by a new line
- 2-print_alphabet_x10.c contains a C function that prints 10 times the alphabet, in lowercase, followed by a new line
- 3-islower.c contains a C function that checks for lowercase character by returning 1 if the character is lowercase and 0 otherwise
- 4-isalpha.c contains a C function that checks for alphabetic character by returning 1 if the character is a letter (lowercase or uppercase) and 0 otherwise
- 5-sign.c contains a C function that prints the sign of a number by, returning 1 and printing + if the number is greater than 0, returning 0 and printing 0 if the number is 0, and by returning -1 and printing - if the number is less than 0
- 6-abs.c contains a C function that computes the absolute value of an integer
- 7-print_last_digit.c contains a C function that prints the last digit of a number
- 8-24_hours.c contains a C function that prints every minute of the day of Jack Bauer, starting from 00:00 to 23:59
- 9-times_table.c contains a C function that prints the 9 times table, starting with 0
- 10-add.c contains a C function that adds two integers and returns the result
- 11-print_to_98.c contains a C function that prints all integers from n to 98, followed by a new line, numbers separated by a comma, followed by a space, in order, with the first number printed being the number passed in the function and the last being 98
